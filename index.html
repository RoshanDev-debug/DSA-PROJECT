About this project

What is an array?

An array stores elements one after another in memory. Every element has an index that starts at 0, so any element can be reached directly by its index.

ArrayX keeps a real JavaScript array and runs every operation on it. The boxes on screen are redrawn from that array after each step.

DSA concepts demonstrated

  • Zero-based indexing and direct access
  • Insertion by shifting elements to the right
  • Deletion by shifting elements to the left
  • Updating an element in place
  • Linear (sequential) search
  • Best-case and worst-case time complexity
